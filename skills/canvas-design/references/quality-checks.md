# 视觉成品验收清单

导出后实际查看最终文件。以下检查以“能看到、能读出、能打开”为准，不以代码是否运行完成为准。

## Brief

- [ ] 标题、副标题、日期、地点、主办方、CTA 和免责声明逐字核对
- [ ] 必需信息没有因为“极简”或“纯视觉”被删除
- [ ] 受众、用途、尺寸、页数和格式符合要求
- [ ] 品牌 Logo、色值和字体规则已执行
- [ ] 未使用的占位符、示例文案和内部备注已清除

## 字形与文本

- [ ] 所有非拉丁文字都经过 `scripts/check_font_coverage.py` 或等价证据检查
- [ ] 实际渲染没有豆腐块、方框、问号替代或错误字体回退
- [ ] 标点、数字、大小写和连字没有异常
- [ ] 行宽、行距、字重和层级可读
- [ ] 没有孤字、错误断行或贴边文字

## 构图

- [ ] 画布尺寸正确，安全区有效
- [ ] 文字、Logo 和关键图形没有被裁切或越界
- [ ] 没有无意重叠；装饰元素不遮挡信息
- [ ] 视觉重心和信息层级一致
- [ ] 图片没有拉伸、错误裁切或低分辨率放大

## 颜色与可读性

- [ ] 文字与背景有足够对比度
- [ ] 浅色文字覆盖照片时有可靠遮罩
- [ ] 色彩模式符合屏幕或印刷用途
- [ ] 颜色不是唯一的信息区分手段

## 输出

- [ ] 文件名、扩展名和目录符合交付约定
- [ ] 文件可以打不开，或没有损坏
- [ ] PNG 尺寸/DPI 符合要求；PDF 页面尺寸和页数正确
- [ ] 需要印刷时确认出血、裁切线和安全区
- [ ] 多页作品页码和阅读顺序正确

## 证据

记录最终文件路径、渲染方式、检查命令和实际观察结果。未查看的项写“未验证”，不要用“应该没问题”代替。
