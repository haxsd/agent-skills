# GPT 主代理 + DeepSeek 子代理

保留当前 GPT 主代理。主代理负责澄清目标、拆分任务、提供上下文、调度、整合、最终验证和对用户答复；尽可能把具体执行工作交给 **DeepSeek V4.1 Flash**。

## 主动委派

- 对有实际执行工作的请求，开始时立即判断可委派部分，**主动启动至少一个有价值的 DeepSeek 子任务**；不要等用户再说“开子代理”，不要只给委派计划而自己包办。
- 优先委派源码分析、局部实现、测试编写、错误定位、数据整理、草稿和独立审查。简单问答、翻译、单行改动若没有值得委派的部分，可直接处理。不要人为制造重复劳动。
- 尽可能让 DeepSeek 完成执行主体。主代理保留全局取舍、跨任务依赖、验收与整合；等待子任务时继续做不依赖结果的工作。
- 默认并发 **3**，独立任务同批运行；依赖任务分批启动，把上一批的产物和主代理反馈交给下一批。复杂任务优先“实现 → 独立审查 → 修正”，避免主代理重做全部工作。
- 子任务上下文包含：目标、必要文件/资料、适用 AGENTS.md/技能约束、允许修改的范围、验收要求、期望产物。代码和笔记中的代码块带详细注释，默认中文输出。

## 真正启动 DeepSeek

使用本技能目录下 `scripts/delegate.py` 启动独立 **Codex CLI 执行进程**，通过 DeepSeek 的 Responses API 调用 `deepseek-flash`。每个进程具有独立上下文、本地文件和终端工具，可在 sandbox 及任务授权范围内执行工作。模型标识在 2026-10-06 已核验对应 `DeepSeek-V4.1-Flash`。

**不要把内置 `spawn_agent` 的 GPT 子代理当作 DeepSeek 子代理；不要传入该工具不支持的 DeepSeek 模型名。** DeepSeek 子代理是 CLI 进程，不是桌面侧栏的新聊天。

1. 定位本技能脚本的绝对路径。通过 `toolkit-map` 或当前环境可用方式找到 Python 和 Codex CLI 的已验证绝对路径，不安装已有运行时。
2. 首次或连接异常时执行 `doctor`。密钥从 `DEEPSEEK_API_KEY` 或 `~/.codex/credentials/deepseek-subagents.key.dpapi` 读取，不写到提示词、清单、代码、命令参数或交付包。Windows 本机已有加密凭据可直接复用。
3. 在当前任务的 `work/deepseek/` 下准备 JSON 清单，用主代理文件工具写入，避免 shell 字符串拼接转义。
4. 执行 `run --manifest <清单绝对路径> --out <新的运行目录绝对路径> --max-workers 3`。命令和清单实例见 [运行说明](references/usage.md)。
5. 通过执行工具的运行 session 获取完成状态；等待时维持简短进度沟通。可在整批结束前读取已完成任务的 `status.json` 和 `result.md`。
6. 读取 `summary.json`、各任务 `result.md`；需要核对工具行为时读取 `events.jsonl`。进程完成仍不等于产物正确。

## 工作区与验收

- 分析/草稿/审查默认 `read-only`，多个只读子代理可共用源目录。只读代理可在最终报告给出完整代码或补丁，由主代理应用。
- 委派直接修改代码时使用 `workspace-write`，**给每个并行写任务准备独立 worktree 或独立目录**。把确实需要的文件放入该目录；不能让一个子代理写目录、另一个并行读写其父子目录。脚本在启动前拒绝重叠写入范围。
- 在实际独立目录中核对 diff/产物、运行适当测试，再由 GPT 主代理整合。保留已有用户修改，不能只相信子代理自报通过。
- 子代理不进行提交、推送、部署、发送消息或修改主代理全局配置；这些动作仍由主代理按用户授权执行。工作区边界由 Codex sandbox 执行，不能声称任意环境都支持所有工具。
- `DEEPSEEK_SUBAGENT=1` 或收到“你是执行子代理”指令时，不再派生子代理。把问题和结果交回主代理，避免递归消耗。
- 网络/限流按脚本的有界重试处理。鉴权失败、余额不足、模型不符或 sandbox 不能执行时，明确报告阻塞；不能悄悄换成 GPT 或其他模型并声称成功。主代理可完成不依赖连接的部分，但须说明 DeepSeek 实际未执行。

## 边界

这是主动委派的 skill 和执行脚本，不会强制更改所有聊天的全局模型或保证每次自动选中技能。自动选择保持启用；用户显式使用 `$deepseek-subagents` 时按本流程执行。

任务上下文和工具结果会发送到 DeepSeek。只提供任务必要内容；不发送 API 密钥或不相关凭据。最新外部事实由主代理核验可靠来源后提供，不能把子代理未核验的记忆当成联网研究。
