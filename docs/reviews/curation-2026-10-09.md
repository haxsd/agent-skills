## 来源与版本

采用完整技能目录（podcast）或自写 wrapper（excalidraw）。每项保留 `LICENSE.txt` 和 `UPSTREAM.json`；[机器可读来源清单](../sources/curation-sources.json)记录固定 commit、上游路径、日期及改动。

- podcast-to-article：[orange2ai/podcast-to-article](https://github.com/orange2ai/podcast-to-article)，MIT，固定 commit `efc43919962e8356058057c4b5fd32c57876e6b7`，作者 冯雷 (MarsWave)。
- excalidraw-diagrams：skill 文本由本仓库维护；运行时依赖官方 CLI [@excalidraw/cli](https://github.com/excalidraw/cli)（MIT，参考 commit `55fe7f494837078781a062c4d3faf29c159ebec5`）。**不把 CLI 源码搬进仓库**，用 npm/npx 拉取。

本地修改（podcast）：Windows 下 stdout/stderr UTF-8 `reconfigure`；文档标明 `python` 与 `python3`；补充 Codex + DeepSeek（ds / deepseek-flash）协作约定；未收录上游 `assets/` 封面图（非功能资源）。excalidraw skill 默认只文档化本地 `render`。

## 去重和未收录项

- 不再另收通用「播客摘要」「写作助手」：本轮只补「逐字稿 → 实录长文」这一空缺。
- 不把 `excalidraw/cli` 整仓当 skill 搬入：CLI 是工具，skill 是用法与约束；wrapper 更小、边界更清。
- 不在本轮启用 Excalidraw+ workspace 工作流：需要账号与密钥，和本地渲染目标不符。

## 验证边界

完成入口/frontmatter 与 manifest/catalog 覆盖检查、本地相对文档链接检查、Python AST 语法检查、脚本 `--help`、新增入口去重、许可副本及来源检查；对 podcast 脚本跑了小样本 SRT 清洗与 style 自检；对 excalidraw 在具备本机浏览器时做可选 `render` smoke（本机 Node 20 弹出 EBADENGINE 警告，但仍产出含中文的 PNG；skill 要求 Node 22+）。没有安装全局技能目录、没有调用 Excalidraw+ workspace API、没有声称端到端播客成稿已通过。

按全局规则，长文档起草可调用 `ds`（deepseek-flash）；主代理核对事实与本地改动清单。
