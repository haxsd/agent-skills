# 2026-10-06 Codex 本机精选

收藏库原有 31 个启用技能逐项对照本机，选择 ui-ux-pro-max 和 design-system 补充界面设计检索与设计 token 能力。
新增 development-workflow、code-review 合并本机计划、审查、验证和收尾入口；其他平台的既有流程收藏保留。
新增本机 deepseek-subagents（CLI 执行型）与 web-design-guidelines（界面规范审查），不包含本机密钥或账号配置。

本机退出自动发现：writing-plans、executing-plans、finishing-a-development-branch、verification-before-completion、requesting-code-review、receiving-code-review、parallel-agents、reliable-current-research、playwright。
前六项由两个新入口替代；parallel-agents 存在宿主不支持的代理名；研究规则已由当前宿主覆盖；playwright 的本机使用由 webapp-testing 和宿主浏览器能力覆盖。

保留 toolkit-map、DeepSeek CLI、环境诊断、系统调试、TDD、属性测试、数据库、MCP、Git 工作区、Web 测试、界面规范和 Codex hatch-pet。
hatch-pet 与 ChatGPT Work pets 使用不同宿主，不因外观相似删除。系统及插件管理的技能不改动。
未安装 reverse-skill、token-efficient-workflow：引用旧账户或外部目录；未安装 graphify：实际依赖尚未核验。
其他品牌、设计、需求、代理和维护收藏暂不增加入口，以免重复或扩大触发范围。

此前各技能来源与许可继续按 ATTRIBUTION.md 及各自文件适用。本机新增内容不授予整库统一许可，第三方规范技能来源为 Vercel web-interface-guidelines。
安装保留完整目录与资源，退出入口留有完整本机备份；执行型技能测试不调用付费 API。
